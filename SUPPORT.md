# Support

- **Questions, bugs and ideas:** open an issue using one of the [issue forms](https://github.com/OpenRod/OpenRod/issues/new/choose).
- **Security vulnerabilities:** report them privately, as described in [SECURITY.md](SECURITY.md).
- **OpenShell itself** (gateway, CLI, sandboxes): see [NVIDIA OpenShell](https://github.com/NVIDIA/OpenShell).
